# 🤖 AI Rule-Based ChatBot

A simple Rule-Based AI ChatBot built using Python.

This project was created as part of the DecodeLabs AI Industrial Training Program.

---

## 🚀 Features

- Rule-Based Response System
- Infinite Chat Loop
- Fast Dictionary Lookup
- Input Sanitization
- Typing Animation Effect
- Colored Terminal Output
- Dynamic Random Responses

---

## 🧠 Technologies Used

- Python
- Dictionary Mapping
- Control Flow Logic
- Colorama

---

## ⚡ Complexity

```text
Dictionary Lookup → O(1)
```

Using Dictionary Mapping instead of long if-elif ladders makes the chatbot faster and cleaner.

## ▶️ Run The Project

Install requirements:

```bash
pip install -r requirements.txt
```

Run chatbot:

```bash
python chatbot.py
```
