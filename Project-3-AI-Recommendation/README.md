# 🚀 AI Career Recommendation Engine Pro

An intelligent AI-powered Career Recommendation System that helps users discover the most suitable career paths based on their skills using Machine Learning techniques.

---

## 📌 Overview

AI Career Recommendation Engine Pro analyzes user skills and recommends the most relevant career roles using:

* TF-IDF Vectorization
* Cosine Similarity
* Skill Gap Analysis

The system also identifies:

* ✅ Matched Skills
* ❌ Missing Skills
* 🎯 Best Career Match
* 📊 Match Score

---

## ✨ Features

### 🔹 Career Recommendation

Get the top 5 career recommendations based on your skills.

### 🔹 Skill Gap Analysis

Discover which skills you already have and which skills you need to learn.

### 🔹 Interactive Skill Selection

Select skills using numbers instead of typing full names.

### 🔹 Rich Terminal Dashboard

Modern terminal interface built using Rich Library.

### 🔹 Similarity-Based Matching

Uses TF-IDF and Cosine Similarity for intelligent recommendations.
